## V1-16 实现 MIDI 导入页面

### 背景
v0.1 的入口页面（PRD §4.2/§14）。

### 问题
文件选择/拖拽导入 → 调用 `import_midi` → 曲谱库列表（空状态、错误状态）。

### 目标
导入页 + 曲谱库 store（Pinia）+ 解析错误展示 + 最近列表持久化（tauri-plugin-store）。

### 用户价值
用户迈出第一步。

### 范围
- 文件选择（tauri dialog）+ 拖拽
- `import_midi` IPC 接入；解析在后台线程
- 曲谱库列表（名称/轨道数/时长/时间）
- 错误模态（错误码 → 可读文案映射）

### 非目标
拖拽到游戏窗口等复杂交互、批量导入、曲谱搜索。

### 技术建议
- 大文件上限 50MB 前端先行校验；
- 状态管理：Pinia store（documents、current_document）。

### 依赖关系
V1-04。

### 验收标准
1. 合法 MIDI 导入成功并出现在列表；2. 非法文件错误可读；3. 空状态引导可见；4. 重新导入覆盖。

### 测试要求
Vitest：store 状态、错误映射；Playwright：导入流程（Mock 后端）。

### 文档要求
用户文档「导入曲谱」。

### 风险
拖拽在 WebView 的兼容性；fallback 到文件选择。

### 完成定义
UI 测试全过 + 手动流程验证。

## V1-17 实现轨道选择页面

### 背景
多轨 MIDI 需要选择演奏轨道（PRD §4.3）。

### 问题
曲谱详情页：基本信息 + 轨道列表（启用开关、音符数、名称）+ 进入转换。

### 目标
详情页 + 轨道启用状态持久（会话内）。

### 用户价值
选择主旋律、排除打击乐轨。

### 范围
- 轨道列表与启用/禁用
- 全禁用拦截（阻止进入演奏）
- 基本信息展示（格式/时长/BPM 范围/音符数）

### 非目标
音色预览、波形显示、轨道重命名。

### 技术建议
启用状态存 store；编排时传入轨道子集。

### 依赖关系
V1-16。

### 验收标准
1. 多轨正确显示；2. 全禁用阻止演奏并提示；3. 单轨可演奏。

### 测试要求
Vitest：store 逻辑；组件测试。

### 文档要求
用户文档「选择轨道」。

### 风险
轨道名缺失（显示「轨道 N」兜底）。

### 完成定义
测试全过 + 手动验证。

## V1-18 实现转换参数页面

### 背景
编排参数入口（PRD §4.4）。

### 问题
自动转调/手动移调/音域策略/最大复音/量化/和弦简化控件 + 实时编译（防抖）+ 摘要（移调量、丢弃数、裁剪数）。

### 目标
参数页 + `compile` IPC + ArrangementOptions 校验 + 结果摘要展示。

### 用户价值
精细控制演奏效果。

### 范围
- 六类控件（滑杆/下拉/开关）
- 防抖 200ms 重新编译
- 摘要徽标（保留率等）
- 参数可保存为「我的预设」（本地）

### 非目标
参数自动推荐（v0.3）、多套预设管理。

### 技术建议
前端构造 ArrangementOptions JSON → invoke compile；后端纯函数编排（V1-07~V1-10）。

### 依赖关系
V1-07、V1-08、V1-09、V1-10。

### 验收标准
1. 每个控件变更触发重编译；2. 摘要正确；3. 非法组合（复音 0）被拒绝；4. 预设保存/恢复。

### 测试要求
Vitest：参数校验、防抖、store；后端编排集成测试。

### 文档要求
参数含义说明（tooltip）。

### 风险
编译耗时（大曲目）；后台线程 + 进度指示。

### 完成定义
UI 测试全过 + 编排集成验证。

## V1-19 实现钢琴卷帘预览

### 背景
演奏前可视化（PRD §4.5）。

### 问题
只读钢琴卷帘：时间轴/音高轴、音符矩形、缩放、播放头联动、当前音符高亮。

### 目标
卷帘组件 + 数据适配（CompiledSequence → 渲染模型）+ 与播放事件联动。

### 用户价值
确认编排结果再演奏。

### 范围
- 横向时间（µs → 秒显示），纵向音高（音名标注）
- 缩放 0.5x–4x；hover 详情
- 播放头订阅 `playback://progress`

### 非目标
编辑（v0.3）、多轨分色（先单色按轨道区分）。

### 技术建议
Canvas 或 SVG 渲染（性能测试后定）；数据来自编译结果而非实时重算。

### 依赖关系
V1-11。

### 验收标准
1. 音符位置/时长正确（黄金样例比对）；2. 缩放不漂移；3. 播放头实时联动；4. 万级音符不卡顿。

### 测试要求
组件测试（渲染计数、坐标计算）；性能冒烟。

### 文档要求
用户文档「预览」。

### 风险
渲染性能；Canvas 兜底方案。

### 完成定义
组件测试过 + 性能冒烟过。

## V1-20 实现播放控制界面

### 背景
演奏核心 UI（PRD §4.6/§8）。

### 问题
倒计时、开始/暂停/继续/停止/紧急停止、速度、进度/当前音符显示、风险二次确认、窗口聚焦检查。

### 目标
播放控制组件 + `playback://state/progress` 事件订阅 + 全部控制命令接通。

### 用户价值
可控、可见的演奏体验。

### 范围
- 状态机 UI（Idle/Countdown/Playing/Paused/**Stopped**/Finished；Stopped 为停止与紧急停止后的终态，重新开始回到 Idle）
- 3 秒倒计时（可取消）
- 速度 0.5x–2.0x（演奏中可调）
- 风险确认对话框（每次演奏前）
- 前台窗口检查提示（未聚焦 → 提示并挂起）
- **窗口失焦自动暂停**（可配置，默认开启；暂停而非紧急停止）
- 当前音符名显示

### 非目标
波形可视化、录音、循环播放（v0.3 评估）。

### 技术建议
- 前端状态 = 后端事件唯一事实源（不做本地猜测）；
- 紧急停止按钮常驻可点。

### 依赖关系
V1-12、V1-14、V1-15。

### 验收标准
1. 全状态流转正确（含倒计时取消与 Stopped 终态）；2. 速度调整即时生效；3. 风险确认不可跳过；4. 未聚焦提示正确；5. 失焦自动暂停生效（可配置关闭）。

### 测试要求
Vitest：状态机映射；Playwright：倒计时→播放→暂停→停止全流程（Mock 后端）。

### 文档要求
用户文档「演奏控制」；PRD §8 同步。

### 风险
窗口聚焦竞态；以用户确认 + 兜底提示处理。

### 完成定义
e2e 流程通过 + 手动验证。

## V1-28 实现设置页面与本地日志系统

### 背景
v0.1 必须项「本地设置、本地日志」（PRODUCT_PLAN §7）；设置页是 Profile 选择、快捷键配置（V1-21）、风险重看的宿主；日志系统（ARCHITECTURE §13）支撑诊断与崩溃追溯。

### 问题
设置页与日志基础设施在 27 项拆解中无归属。

### 目标
设置页（Profile 选择/快捷键/日志/风险重看/关于）+ tracing 日志系统（滚动文件、级别配置、脱敏）+ 配置存储（tauri-plugin-store）。

### 用户价值
用户可配置行为、查看诊断信息。

### 范围
- 设置页：Profile 选择（默认 identity-v）、快捷键显示与更换、日志级别/目录/清理、风险提示重看、关于（版本/许可证/隐私声明）
- 日志：tracing + tracing-subscriber → 滚动文件（保留 7 天），默认 info，可配置 debug；不含文件内容，文件名可脱敏；可配置关闭
- 配置存储：`<data_dir>/settings.json`（tauri-plugin-store），风险确认状态持久化

### 非目标
多 Profile 管理、预设导入导出、日志上报。

### 技术建议
- 日志初始化在 main 早期完成（panic hook 前）；
- 配置读写收敛到 scoreleap-core 单一模块。

### 依赖关系
V1-02（质量框架）、V1-21（快捷键配置写入设置）。

### 验收标准
1. 设置项持久化且重启生效；2. 日志文件生成/轮转/级别切换正确；3. 风险重看入口可用；4. 快捷键冲突提示可达设置页。

### 测试要求
Vitest：设置 store；Rust：日志初始化与配置读写单测。

### 文档要求
用户文档「设置」章节。

### 风险
日志泄漏路径信息；默认级别 info + 文档说明。

### 完成定义
设置持久化验证通过 + 日志测试全过。
