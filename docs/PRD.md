## 1. 用户故事

| ID | 角色 | 故事 | 验收要点 |
|---|---|---|---|
| US-01 | 玩家 | 导入本地 `.mid` 文件并查看曲目信息 | 显示曲名、格式、轨道数、时长、BPM 范围 |
| US-02 | 玩家 | 选择要演奏的轨道 | 多轨可勾选，至少选 1 轨 |
| US-03 | 玩家 | 自动转调让曲子适配乐器音域 | 一键「自动适配」，显示移调量 |
| US-04 | 玩家 | 手动移调 | 半音步进 ±24，预览即时更新 |
| US-05 | 玩家 | 折叠超出音域的音符 | 策略可选：降八度/丢弃/静音 |
| US-06 | 玩家 | 限制同时发声数 | 设置最大复音（默认 4），超限自动裁剪 |
| US-07 | 玩家 | 量化节奏 | 可选网格（1/8、1/16、关闭） |
| US-08 | 玩家 | 简化和弦 | 保留根音/旋律音策略 |
| US-09 | 玩家 | 预览演奏时间轴 | 钢琴卷帘展示音符 + 播放头 |
| US-10 | 玩家 | 在游戏内自动演奏 | 倒计时 3s 后按时间轴按键 |
| US-11 | 玩家 | 随时暂停/继续/停止 | 快捷键 + UI 双通道 |
| US-12 | 玩家 | 紧急停止 | 立即释放全部按键，全局快捷键 |
| US-13 | 玩家 | 调整播放速度 | 0.5x–2.0x |
| US-14 | 玩家 | 查看当前演奏进度与音符 | 进度条 + 当前音符高亮 |
| US-15 | 玩家 | 测试按键是否有效 | Windows 测试页面（记事本） |

| US-17 | 玩家 | Android 通知栏控制 | 暂停/停止，前台常驻 |
| US-18 | 用户 | 首次使用了解风险 | 风险确认页，不可跳过 |

## 2. 用户操作流程（v0.1 主流程）

```
启动应用
  └─ 首次启动 → 风险确认页 → 同意
  └─ 首页（曲谱库/导入入口）
导入 MIDI（拖拽或文件选择）
  └─ 解析成功 → 曲谱详情页（轨道列表）
  └─ 解析失败 → 错误提示（可重试）
选择轨道 → 转换参数页（转调/音域/复音/量化/和弦）
  └─ 实时预览钢琴卷帘
开始演奏
  └─ 风险二次确认 → 窗口聚焦检查 → 3 秒倒计时
  └─ 演奏中：进度显示 / 暂停 / 继续 / 停止 / 紧急停止
  └─ 演奏结束：全部按键释放，回到详情页
```

## 3. 页面信息架构

```
ScoreLeap
├── 风险确认页（首次启动，gate）
├── 主界面（单窗口，Tab 导航）
│   ├── 曲谱库（最近导入列表 + 导入入口）
│   ├── 曲谱详情（轨道列表、基本信息、操作）
│   ├── 转换参数（转调/音域/复音/量化/和弦）
│   ├── 钢琴卷帘预览（内置在转换参数页或独立页）
│   ├── 演奏控制（倒计时/进度/当前音符/控制按钮）
│   ├── 测试页（Windows 按键测试）
│   ├── 设置（Profile 选择、快捷键、日志、关于）
│   └── 校准向导（Android v0.2）
└── 对话/模态
    ├── 风险确认对话框（每次演奏前）
    ├── 错误提示
    └── 紧急停止确认（长按/快捷键时）
```

## 4. 每个页面的功能

### 4.1 风险确认页（gate）
- 展示：第三方自动化风险提示全文、仅限自由演奏场景声明、隐私承诺；
- 操作：勾选「我已阅读并理解」+ 点击「同意并继续」才可进入；
- 状态持久化：本地存储（可在设置中重新查看）。

### 4.2 曲谱库
- 空状态：引导导入（拖拽/选择文件）；
- 列表：文件名、轨道数、时长、最近打开时间；点击进入详情；
- 支持重新导入覆盖。

### 4.3 曲谱详情
- 基本信息：格式、Tempo 范围、音符数、轨道列表（名称/音符数/启用开关）；
- 操作：进入转换参数、删除曲谱；
- 错误状态：解析失败显示原因与重试。

### 4.4 转换参数
- 自动转调按钮（依据 Profile 音域计算建议移调量）；
- 手动移调滑杆（-24 ~ +24 半音，步进 1）；
- 音域折叠策略（降八度/丢弃/静音）；
- 最大复音（1–8，默认取 GameProfile.max_polyphony，UI 可覆盖）；
- 量化网格（关闭/1/8/1/16）；
- 和弦简化开关（保留旋律音优先）；
- 每个变更即时重新编译时间轴，预览同步更新。

### 4.5 钢琴卷帘预览
- 横向时间轴（秒/小节），纵向音高；
- 音符矩形着色（启用轨道 vs 静音轨道）；
- 播放头随演奏移动；演奏中高亮当前音符；
- 缩放（时间轴 ×0.5–×4）；
- 只读（v0.1），编辑能力 v0.3。

### 4.6 演奏控制
- 状态机：`Idle → Countdown → Playing ⇄ Paused → Stopped（终态）`；用户重新发起会话时回到 Idle；
- 按钮：开始/暂停/继续/停止/紧急停止；
- 倒计时 3s（数字 + 声音可选）；
- 进度：已播放/总时长、百分比、当前音符名；
- 速度控制 0.5x–2.0x（演奏中可调）。

### 4.7 Windows 测试页
- 显示目标窗口检测状态；
- 选择「测试模式」：按键输出到当前聚焦窗口（如记事本）；
- 每个映射键可单独测试（按下/抬起显示）；
- 提示：正式演奏请聚焦游戏窗口。

### 4.8 设置
- Profile 选择（当前 `identity-v`）；
- 全局快捷键配置（开始/暂停、紧急停止）；
- 日志级别、日志目录打开、日志清理（日志可配置关闭，文件名可脱敏）；
- 风险提示重新查看；
- 关于（版本、许可证、隐私）。

### 4.9 校准向导（Android v0.2）
- 步骤 1：说明与权限（无障碍服务开启引导）；
- 步骤 2：横屏进入游戏，点击实际琴键位置（至少低/中/高 3 个锚点）；
- 步骤 3：保存为 CalibrationProfile（命名、设备/分辨率记录）；
- 步骤 4：测试模式（单键试触）。

## 5. 错误状态

| 场景 | 表现 | 恢复 |
|---|---|---|
| 文件解析失败 | 模态错误 + 原因（格式不支持/损坏） | 重试/换文件 |
| 文件过大（>50MB） | 拒绝并提示 | 换文件 |
| Profile 加载失败 | 设置页错误徽标 + 详细原因 | 修复 profile 或恢复默认 |
| 演奏启动时无聚焦窗口 | 提示聚焦游戏窗口，倒计时挂起 | 聚焦后重试 |
| 注入失败（权限/系统） | 停止并释放按键 + 错误提示 | 检查系统环境 |
| 调度器异常 | 自动紧急停止 + 错误日志 | 查看日志 |
| Android 无障碍未授权 | 引导开启 | 用户操作 |
| Android 手势超时 | 跳过该音符并记录日志 | 继续播放（重试策略可配，默认不重试） |

## 6. 空状态

- 曲谱库为空：插图 + 「导入第一份 MIDI」按钮；
- 轨道全部禁用：阻止开始演奏并提示「至少启用一个轨道」；
- 编排后音符数为 0（全部被折叠/裁剪）：提示调整参数，不进入演奏；
- 测试页无目标窗口：提示打开记事本或游戏。

## 7. 权限状态

| 权限/前提 | 状态检查 | 未满足时的行为 |
|---|---|---|
| 文件读取 | 无特殊权限（文件选择器） | 系统级拒绝时提示 |
| 全局快捷键 | 注册失败提示（冲突） | 设置中更换快捷键 |
| 前台窗口（Windows） | 每次演奏前检查 | 提示聚焦目标窗口 |
| 无障碍服务（Android） | 演奏前检查 | 引导开启（设置页跳转） |
| 悬浮窗（Android） | 非必需 | 无 |
| 网络 | 完全不需要（本地模式） | 无 |

## 8. Windows 播放流程（v0.1）

1. 用户点击「开始演奏」；
2. 风险确认对话框（每次演奏前）；
3. 检查：Profile 有效、轨道 ≥1、音符 >0、目标窗口确认；
4. 进入倒计时 3s（期间可取消）；
5. Scheduler 按 CompiledSequence 的整数微秒时间轴触发按键事件（按下/抬起成对）；
6. 全程状态可见（进度、当前音符、已按键计数）；
7. 暂停：立即释放所有已按下按键，冻结时间轴；
8. 继续：从冻结位置恢复（重新按下持续音符）；
9. 停止/结束：释放全部按键，进入 Stopped 终态；
10. 紧急停止（默认快捷键 Ctrl+Alt+F9）：任意状态立即释放全部按键并复位至 Stopped。

## 9. Android 播放流程（v0.2）

1. 用户点击「开始演奏」；
2. 检查无障碍服务授权 + 校准 Profile 存在 + 风险确认；
3. 启动前台服务（通知：曲名、暂停、停止）；
4. 倒计时 3s（可取消）；
5. Scheduler 将时间轴转为手势流：单音 = 单点 tap；持续音符 = 长按手势（continueStroke/willContinue 续接）或降级为重复 tap（策略可配）；和弦 = 多点同时 dispatchGesture；
6. 通知栏实时更新进度；可暂停/继续/停止；
7. 手势失败（超时/拒绝）→ 跳过该音符并记录日志（重试策略可配，默认不重试）；
8. 停止/完成：取消所有未完成手势，通知转「已结束」，服务退出；
9. 屏幕旋转/分辨率变化：按当前校准 Profile 重新映射坐标（归一化坐标）。

## 10. 首次使用引导

- 步骤 1：欢迎页（产品定位一句话）；
- 步骤 2：风险与合规确认（必须同意）；
- 步骤 3：选择目标 Profile（默认 identity-v）；
- 步骤 4：引导导入第一份 MIDI（可跳过）；
- 引导进度可跳过（除风险确认外），设置中可重放。

## 11. 琴键校准流程（Android，v0.2）

1. 校准向导进入「校准模式」；
2. 应用切到横屏，用户在游戏乐器界面点按琴键；
3. 每次点击记录归一化坐标（x/width, y/height）并映射到音名；
4. 最少校准 3 个锚点（最低键、中央键、最高键），推荐全键校准；
5. 线性插值生成完整键位表；
6. 保存 CalibrationProfile（含设备型号、分辨率、日期）；
7. 测试模式试触确认；可随时重新校准。

## 12. 模型下载流程（v0.4）

1. 用户启用音频转 MIDI → 检测模型缺失；
2. 显示模型信息（名称、大小、许可证、来源 URL、SHA256）；
3. 用户确认下载（可离线从发布页手动下载后导入）；
4. 下载 → SHA256 校验 → 解压到模型目录；
5. 失败重试/断点续传（评估）；校验失败不加载并提示；
6. 下载与转换均本地，不上传音频。

## 13. 紧急停止流程

- 触发入口：全局快捷键（默认 Ctrl+Alt+F9）、UI 按钮、Android 通知栏停止；
- 行为：立即停止时间轴推进 → 释放全部已按下按键/取消全部手势 → 进入 Stopped 终态 → 日志记录触发原因；
- 紧急停止优先级高于一切播放状态（含倒计时）；
- 窗口失焦为**可配置的自动暂停**（非紧急停止），默认开启；
- 崩溃兜底：panic hook + SetUnhandledExceptionFilter 与进程退出处理尽力释放按键；启动自检（状态文件 + GetAsyncKeyState）补抬残留按键；无法保证时，指引用户重启游戏恢复按键状态。

## 14. 曲谱导入和转换流程

1. 选择/拖拽文件（.mid/.midi）；
2. 解析：格式检查 → 事件流 → Music IR（Tempo Map、轨道、NoteEvent）；
3. 校验：轨道数、音符数、时长；失败进错误状态；
4. 用户配置编排参数（转调/音域/复音/量化/和弦）；
5. 编排：转调 → 音域处理 → 和弦简化/复音限制 → 量化 → 映射 Profile；
6. 编译：生成 CompiledSequence（整数微秒时间轴 + PlatformAction）；
7. 预览或演奏。

## 15. 曲谱预览流程

- 参数变更 → 重新编译（防抖 200ms）→ 卷帘刷新；
- 播放头联动；hover 显示音符信息（音名、时刻、时长、轨道）；
- 演奏时预览实时跟随（主线程 UI，编排在后台线程）。

## 16. 风险确认流程

- 首次启动：整页确认（见 4.1）；
- 每次演奏前：对话框确认（「本次演奏仅用于自由演奏/个人空间场景」）；
- Android：开启无障碍服务前单独解释用途与范围；
- 确认记录存本地（仅 UI 状态，不含遥测）。
