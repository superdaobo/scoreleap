# ADR-0008：MAESTRO 真值验收标准调整为等价性门槛

状态：已接受（2026-08-05，用户确认）

## 背景

计划中的转录质量门槛（Precision ≥ 0.93、Recall ≥ 0.87、Onset F1 ≥ 0.90、
Onset+Offset F1 ≥ 0.75、误音 ≤ 3/分钟）原计划同时应用于 MAESTRO 独立真值集、
20dB 噪声集与用户样本隐藏区。

## 实测事实（5 个 MAESTRO v3 样本，覆盖 train/validation/test）

- 原生实现与官方 Basic Pitch 输出**逐音符等价**：样本 92（test）一致 F1 = 0.9992，
  样本 252（validation）一致 F1 = 1.0（音符数 603/604 与 388/388）。
- Basic Pitch 官方模型在 MAESTRO 密集钢琴曲目上的绝对质量上限（官方实现同样）：
  Onset F1 0.47~0.70、Precision 0.60~0.86、Recall 0.32~0.55、
  Onset+Offset F1 0.009~0.199、误音 65~185/分钟。任何参数组合都无法同时满足原门槛
  （Recall 升至 0.88 时 Precision 跌至 0.30）。
- Onset+Offset F1 极低的根因是标注语义冲突：MAESTRO 参考音符中位时长仅约 46ms，
  Basic Pitch 输出最短音符约 120ms，offset 容差（max(50ms, 时长×20%)）几乎不可能命中。

## 决策

1. MAESTRO 真值验收改为：**实现与官方 Basic Pitch 逐音符等价，一致性 F1 ≥ 0.99**
   （当前实测 0.9992 / 1.0）。模型对密集曲目的绝对质量上限如实记录，不再作为发布门槛。
2. 产品验收回到用户核心场景：`8月4日.MP3` 校准区（0-120s）/ 隐藏区（120-199.393s）
   分区 + 三预设参数冻结 + 格式一致性（WAV vs FLAC ≥ 0.995、MP3 vs 无损 ≥ 0.97）
   + 性能门禁 + 安装后 E2E，最终由用户听审 `8月4日.MP3` 确认。
3. `gate` 命令保留原硬门槛不变，供**用户样本有人工参考 MIDI 后**做严格验收；
   对无参考样本 `gate`/`evaluate` 返回明确错误。
4. 若后续导入 ByteDance 等更强模型候选，重新按原严格门槛评审（ADR-0006 模型候选
   流程不变）。

## 后果

- 不再以“Basic Pitch 在 MAESTRO 上达到 0.93/0.87/0.90”作为发布条件；
  用户样本听审成为最终发布确认。
- MAESTRO 数据集仍仅存于本机 `D:\tmp`，不随产品分发（ADR-0006 数据边界不变）。
