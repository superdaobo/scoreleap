# ADR-0001：项目范围与合规边界

- 状态：已接受（draft）
- 日期：2026-02（规划期）
- 决策者：Agent A（产品与总体架构）

## 背景

ScoreLeap 是跨平台游戏乐器曲谱转换与辅助演奏工具。目标游戏《第五人格》的自动化输入涉及服务条款风险，且社区存在大量灰色工具。项目需要明确范围与底线，避免产品漂移和合规失控。

## 决策

1. **不绑定单一游戏**：项目名、crate 名、公共接口不出现 Identity V；《第五人格》仅作为第一个 Game Profile（`game-profiles/identity-v/`）。
2. **本地优先**：MIDI/音频/曲谱默认全部本地处理；任何在线功能必须用户显式选择。
3. **硬性底线**：不实现进程内存操作、DLL/驱动注入、Hook、反作弊绕过、隐藏自动化、随机化规避、竞技自动化。
4. **可见可停**：演奏状态全程可见；提供紧急停止与全按键释放；每次演奏前风险确认。
5. **AI 后置**：v0.1/v0.2 无 AI 推理；音频转 MIDI（v0.4）与 Android AI（v0.5）先研究后实现。
6. **MVP 定义**：v0.1.0 仅 Windows MIDI 键盘演奏。

## 后果

- 正面：合规风险可控；核心逻辑可复用；可对外展示安全立场。
- 负面：部分用户期望的「自动竞技」「隐藏运行」明确不被支持；Android 上架受限（GitHub 直发）。

## 替代方案

| 方案 | 评估 |
|---|---|
| 绑定单游戏快速上线 | 违反架构可扩展原则，拒绝 |
| 提供「竞技增强」模式 | 触碰合规底线，拒绝 |
| 依赖在线服务做全部转换 | 违反隐私原则，拒绝 |
